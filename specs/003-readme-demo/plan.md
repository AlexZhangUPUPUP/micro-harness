# 实施计划

1. 主 Agent 制作 GitHub 仓库 Star 按钮点击动画，沿用朱砂橙品牌，输出 `docs/star.gif`。
2. 子 Agent 更新中英文 README 的 Star 引导文案、仓库链接和静态产品截图位置，并调整本轮规范文档。
3. 主 Agent 检查关键帧、循环、文件大小、资源引用和最终 diff，并构建文档站验证 GIF 复制。
4. 动画仅在本地合成，不实际更改账号 Star 状态；本轮不自动提交或推送。

## 实际验证

- 浏览器截取真实仓库页面，裁除浏览器标签页、地址栏与书签区域，保留 `docs/star-repo.png` 用于复现。
- 运行 `python3 scripts/build-star-gif.py`，需本地 Pillow；非 macOS 可通过 `--font` 指定字体。`--button` 是相对源截图的按钮矩形坐标。
- 动画 1200 × 760、32 个优化帧、4.8 秒、126 KiB，循环标志为 0。
- 关键帧人工检查通过；文档构建和 GIF 资源复制校验通过；新增函数均小于 50 行。
- 没有调用真实 Star 接口，没有修改仓库统计或账号状态。
