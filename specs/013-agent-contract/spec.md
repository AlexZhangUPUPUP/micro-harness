# 013 多 Agent 契约

目标：让委派拥有目标、输入范围、权限、产物、验收条件和截止条件，父任务独立核验子任务结果，取消和 race 不遗留后台修改。验收覆盖同文件冲突、超限、假成功和合并后验证失败。

已落地 AgentResult 的结构化终态，以及 task 工具对目标、验收条件和预期产物的契约透传。当前契约状态明确标记为 `unverified`，父任务仍需通过独立检查步骤确认，避免把子 Agent 的自然语言回复误当成验收通过。

## 当前验收边界

- `goal`、`acceptance`、`artifacts` 会随委派结果返回并显示在摘要中。
- 未执行独立验证时，结果只能是 `verification: unverified`。
- 下一步补充验证工具和产物归属检查后，才允许把契约状态改为通过或失败。
