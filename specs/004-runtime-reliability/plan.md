# 实施计划

## 设计

1. 存储：在重放前归零用量派生值，保留非累计元数据，沿用现有事件折叠逻辑。
2. 模型：将流式解析拆成职责明确的小函数，跟踪完成状态和失败原因，集中管理读取器清理。
3. GUI：把会话加载与订阅生命周期提取为可独立测试的逻辑，失效后阻止回调提交；权限和命令请求采用相同的归属校验原则。

## 分工

- 主 Agent：规格、调用关系复核、最终 diff 与验证整合。
- 存储 Agent：仅修改 server 存储及其回归用例。
- 模型 Agent：仅修改 core 流式模型客户端及其回归用例。
- GUI Agent：仅修改 GUI 会话生命周期、相关异步读取及其回归用例。

## 验证

- 存储：累计主、子 Agent 用量后连续重建，检查磁盘与索引统计稳定，保留标题等信息。
- 模型：正常完成、截断、畸形帧、错误帧、长度限制、读取失败、取消、回调异常和资源释放。
- GUI：快照与事件并发、旧请求乱序、旧失败回调、切换会话和取消订阅。
- 整合：相关测试各运行一次；类型检查、GUI 构建与最终 diff 检查。
