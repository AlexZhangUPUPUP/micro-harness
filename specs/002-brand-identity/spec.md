# 002：统一品牌标识

## 目标

将已选定的蓝青渐变 h 标识重绘为透明底 SVG，并统一 README、文档站与 Web 界面的品牌展示。

## 场景与验收条件

1. 中英文 README 顶部展示同一图标，保留现有标题、定位、链接与徽章。
2. 文档构建复制图标，概览图片、侧栏品牌与 favicon 均引用有效资源。
3. Web 顶栏替换原品牌光点，浏览器 favicon 使用相同资源；生产构建能正确解析路径。
4. 图标在深浅背景下清晰可见，相邻品牌文字提供可访问名称，装饰图标不重复朗读。

## 实施与验证

- 单一资源源文件为 `docs/logo.svg`；文档站沿用现有复制机制，GUI 通过 Vite 解析资源。
- 执行文档构建、GUI 构建及 GUI 类型检查，检查输出资源引用与最终 diff。
- 检查 README、文档站及顶栏的视觉布局，不改变业务行为或更新已有截图。
