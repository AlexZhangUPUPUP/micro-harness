# 任务证据与压缩选择

## 问题与范围

上下文压缩会丢失中途用户纠正和工具观察；当前摘要输入的头尾截取甚至没有向模型提供这些信息。本轮先建立独立于模型窗口的来源证据状态，并修复摘要输入选择，不扩展共享预算、执行调度或完整任务生命周期。

## 验收标准

- 用户原始文字和工具观察由独立 task 模块保留，助手回答和摘要不能充当已完成工作的权威凭据。
- 状态有条数、单条字符和投影预算上限；省略明确可见，不宣称无限记忆或自动理解业务状态。
- 压缩时提供按原始顺序排列的证据，保留来源，不将工具文字提升为系统指令。
- 检查点保存任务证据；兼容旧日志，按 Agent 隔离恢复，重复恢复不会放大状态。
- 摘要输入优先用户信息与紧凑的工具观察，不能特判评测标签或读取评分答案。
- 新增针对性测试，复用上下文评测并明确离线与真实模型证据边界。
